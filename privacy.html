Miles Tracker Privacy Policy

Effective 15 October 2026

Miles Tracker is a personal application used only by its owner, who is its only user. This policy describes how it handles data from the owner's Google account.

What data it accesses

With the owner's permission, Miles Tracker uses read-only access to Gmail (gmail.readonly). It reads only emails carrying one label that the owner applies to credit card transaction alerts from their banks. It does not read, modify, send or delete any other email.

What it does with that data

From each alert email it extracts the transaction date, amount, merchant name and the last four digits of the card. It uses these to calculate the owner's monthly card spend and to send the owner status messages in their own Telegram chat.

Where data is stored

Extracted transactions are stored in a database in the owner's own Amazon Web Services account (Singapore region). The Gmail access token is stored encrypted in AWS Secrets Manager in the same account. Full email contents are not stored.

Sharing

Data is not sold, shared with third parties, or used for advertising. Status messages are delivered through Telegram to the owner's own chat.

Google API Services User Data Policy

Miles Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. The owner can delete stored transactions from their AWS account at any time.
